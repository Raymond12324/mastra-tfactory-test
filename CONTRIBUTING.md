# Contributing

## Branches

`main` is the repository's integration branch. Create task work on a branch named `feature/TM-XXX-description`, replacing `TM-XXX` with the tracked work-item identifier and `description` with a short hyphenated summary.

For example, work for TM-005 could use `feature/TM-005-define-repository-conventions`.

## Pull requests

Before opening a pull request:

- Target `main` and use a branch that follows the naming convention.
- Link the associated Linear issue.
- Summarize the change and any relevant implementation details.
- Report the tests, lint, and typecheck commands you ran. If a check does not apply or is unavailable, state that in the pull request.
